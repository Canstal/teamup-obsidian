
产品定位为**大学生课程小组大作业**的**交付协作工具**：
通过“项目需求->任务拆分->分工认领->成果交付->协同验收->统计汇报“的结构化流程，解决——群聊刷屏、通知和文件丢失、文件版本混乱、任务进度不明、协作分工不合理、互评缺少依据、任务推进拖延等大学生大作业常见痛点。
## 一、核心功能：

	1、项目总览、拆分与分工认领
	2、版本数据库
	3、多环节多分工成果交付与协同验收
	4、数据看板
	5、个人智能总结与评价
	6、协作情况一键导出（兼容PPT汇报）
*后续此处会更新链接进一步完善产品功能设计*

## 二、竞品分析：

当前同类型竞品主要有三大类：

1、工作社交软件集成的智能表格功能（[[钉钉]]、[[飞书]]等）；
2、库管理系统自带的办公功能（Notion、[[slack]]、github等）；
3、技术爱好者自行研发的网页（[[teamflow]]等）；

下面将对三大类竞品进行表格分析：

| 竞品       | 核心优势                               | 需求空白                               |
| -------- | ---------------------------------- | ---------------------------------- |
| 钉钉       | 与日常软件集成度高、技术门槛低、AI功能强大、人员联系与数据统计便捷 | 功能复杂、使用门槛不低、AI功能不稳定需要自行设计，仅提供管理者视角 |
| 飞书       | 模板详细功能更完善、技术门槛低                    | 同上，缺少任务交付审核功能，且飞书非我们日常工作平台         |
| slack    | 与codex集成，技术工作流较为便捷                 | 境外平台，功能复杂，收费较高                     |
| github   | 数据库管理更便捷、平台成熟、用户多                  | 功能复杂，无专门任务管理系统                     |
| teamflow | 无                                  | 核心是AI分工，但bug较明显，且实用性较差             |

## 三、产品设计分析：

综合上述竞品分析结果来看，本产品的独特优势在于领域和目标群体足够垂直——针对大学生任务协作。
所以产品特色建议是**轻量化**、**零门槛**、**贴合性**：
逐一说明：
#### 轻量化
1、采用网页+本地存储的产品形式；
2、确保无功能冗余。

#### 零门槛
1、精心设计交互界面，确保功能直观便捷无门槛；
2、根据使用者身份精细区分功能区，区分负责人和执行者；
#### 贴合性
1、围绕大作业的任务全流程，设计包括课堂汇报在内的导出功能；

此外，产品的功能亮点体现在 **阶段性成果交付与审核** 环节AI分析+负责人审核的协作模式，**项目流程透明可视化推进** 的设计，以及 **一键导出全组工作总结** 的美观和展示易用性。

可以发现，相比较同类型竞品，本产品的特点在于**项目推进的可视化**以及**组间协同的细分化**，我们通过拆解任务逐步提交过程性文件并通过AI审核的形式，希望能够起到**有效提升合作效率与个人满足感**的效果。
