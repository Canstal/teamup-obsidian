# 建木枝竞品分析与产品设计

用于课程小组协作产品的竞品研究、体验留痕与设计迭代的 Obsidian 知识库。

## 使用方法

1. 克隆本仓库，或通过 GitHub 的 Code → Download ZIP 下载并解压。
2. 在 Obsidian 中选择“打开本地仓库”，选中本目录。
3. 打开 [00-首页](00-首页.md)，进入竞品总览、体验记录或画布。
4. 在对应体验页添加截图、操作结果和个人感受，再将结论同步至横向对比与决策日志。

## 内容

- `01-产品设计`：合并方案、产品流程、规则、开发范围与验证计划。
- `02-竞品档案`：产品入口、资料来源和体验待办。
- `03-体验记录`：截图、操作记录和感受填写区。
- `04-验证与决策`：统一测试、对比矩阵、假设和决策记录。
- `05-来源`：原方案 Word 快照、提取正文和检索来源。
- `06-模板`：新增体验记录模板。
- `00-导航`：Bases 表格、Canvas 画布、目录与使用说明。
- `竞品体验截图`：体验图片附件。

使用 Obsidian 原生双向链接、Bases 和 Canvas，无需第三方插件。GitHub 网页不会完整呈现这些交互与双向链接，请下载后在 Obsidian 中查看。

官网资料、实测结果和设计假设分别记录。截图存在不代表功能已验证，未填写的个人感受保持为空。价格和权益保留资料日期，实际使用时需复核。

TeamFlow 档案中的本地 Demo 链接指向原电脑仓库外的文件，未包含在此仓库中；其他设备可从该档案列出的开发者来源获取。Obsidian 窗口布局、缓存及本地备份不纳入版本控制。
