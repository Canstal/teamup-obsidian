本目录保存课程小组作业协作调查的问卷版本，便于团队对照与后续修订。

| 版本 | 文件 | 用途 |
| --- | --- | --- |
| 原版 | [下载原版](问卷文本_原版.docx) | 保留初始问卷，供追溯与对照；包含原有编辑备注 |
| 修改版 | [下载修改版](问卷文本_修改版.docx) | 当前拟采用版本，包含15道主问题，补充阶段交付、验收、返工及使用障碍，并调整内测招募表达 |

两份文件于2026年9月24日归档。Word文件请下载后查看；本目录不包含问卷答卷或内测报名信息。

正式发放前先小范围试填，确认跳题、互斥选项和填写时长，并配置独立的内测报名入口。内测福利的具体功能范围、免费期限和参与条件应在正式邀请时明确。问卷为调研工具，尚不代表已获得需求或付费验证。
