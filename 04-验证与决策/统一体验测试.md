# 统一体验测试

优先使用你已有的[[05-来源/测试项目原始记录]]，而非重新虚构人员与任务。各产品使用同一套输入；建议另备v1、v2和故意缺内容的文件，以便测试返工。



- [ ] 创建模拟作业：三人七天完成校园自习空间调研，交付两份模拟访谈记录、一张对比表、一份1000字报告和六页PPT；报告依赖访谈与对比表，PPT依赖报告。全部标注“测试数据”。
- [ ] 设置甲为组长与审核人，乙负责访谈，丙负责分析与PPT；用两个真实测试账号检验跨账号行为，第三名成员可由实际队友参与。单账号角色切换不能证明多人协作。
- [ ] 准备同一文件的v1、v2，另准备一份故意缺内容的文件；设计一次退回、一次改截止时间、一次更换负责人。
- [ ] 先用现有微信群＋共享文档完成相同流程，记录基线：分工用时、成员加入步骤、找定稿用时、整理分工页用时。
- [ ] 为每个产品建立独立记录；同时记录初次配置成本和配置完成后的操作成本。不能拿空白通用工具与预设好的建木枝比较。



以上模拟作业为备用测试方案，不能与用户实际项目混为同一组结果。选定一种后保持跨产品一致。
