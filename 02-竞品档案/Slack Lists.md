# Slack Lists

## 已知信息

官方帮助说明任务、子任务、历史记录，Lists适用于付费方案。

来源：[[05-来源/来源索引#S8]]。此处为资料整理，不是实测结论。

## 获取途径与体验待办

获取：[官方Lists指南](https://slack.com/help/articles/27452748828179-Use-lists-in-Slack)；[官方试用说明](https://slack.com/help/articles/202878523-Try-a-paid-Slack-plan-for-free)。优先使用已有且获得许可的工作空间。Lists属于付费方案；没有权限时先读官方演示，试用需按官方条件申请，不默认可自动开通。预算25分钟。

- [ ] 从列表模板建任务，并尝试将频道中的需求关联到任务。
- [ ] 设置负责人、日期、子任务和相关讨论。
- [ ] 改动任务后查看版本历史及提醒。
- [ ] 测试列表共享、成员和访客的编辑范围。
- [ ] 判断任务与聊天靠近后是否减少重复录入；没获得Lists权限则标未测试。

必须回答：建木枝如何与聊天工具配合，才能减少而非增加沟通负担？
