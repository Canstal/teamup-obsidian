# 建木枝竞品体验待办清单

更新与公开资料核验：2026年9月23日。本文是待执行的体验计划，不是已完成的实测报告。官网功能、演示功能和实际账号权益应分别记录。建议第一轮约4—5人时，第二轮按证据缺口选做；时间为预算，不是已测耗时。

## 先准备同一份测试材料

- [ ] 创建模拟作业：三人七天完成校园自习空间调研，交付两份模拟访谈记录、一张对比表、一份1000字报告和六页PPT；报告依赖访谈与对比表，PPT依赖报告。全部标注“测试数据”。
- [ ] 设置甲为组长与审核人，乙负责访谈，丙负责分析与PPT；用两个真实测试账号检验跨账号行为，第三名成员可由实际队友参与。单账号角色切换不能证明多人协作。
- [ ] 准备同一文件的v1、v2，另准备一份故意缺内容的文件；设计一次退回、一次改截止时间、一次更换负责人。
- [ ] 先用现有微信群＋共享文档完成相同流程，记录基线：分工用时、成员加入步骤、找定稿用时、整理分工页用时。
- [ ] 为每个产品建立独立记录；同时记录初次配置成本和配置完成后的操作成本。不能拿空白通用工具与预设好的建木枝比较。

## 第一轮 必测

### 01 飞书多维表格

获取：[官方项目管理模板](https://www.feishu.cn/template/project-management-template-group)；[官方入门教程](https://www.feishu.cn/content/article/7574713887522639055)；[版本概览](https://www.feishu.cn/content)。登录飞书后选一个项目或任务模板复制，再按测试题改字段。免费系列包含多维表格，但高级权限、AI与自动化的实际配额须在账号中确认；不要混用“飞书项目”另一产品的权益。预算60分钟。

- [x] 从模板建立负责人、截止时间、交付物和审核状态；记录配置耗时。
- [x] 在表格与看板间切换，分别查看全部任务、我的任务和逾期任务。
- [ ] 提交v1并退回，提交v2并确认；测试“成员自己标完成”和“审核人验收”是否能分开。
- [ ] 用第二账号验证查看与编辑权限；如需付费配置，截图记录限制。
- [ ] 尝试生成分工与进度汇总并导出；有AI权益时才补测题目拆解，检查来源是否保留。

必须回答：使用预设模板后，建木枝究竟还能减少哪一步操作？证据：模板链接、配置用时、跨账号截图、导出样例。

### 02 Teambition

获取：[官网与登录入口](https://www.teambition.com/)；[价格页](https://www.teambition.com/pricing)。从官网登录并尝试建项目，选任务模板；如导向钉钉，记录接入过程。官网展示任务跟踪、多视图、模板与报表；免费可用范围以当前账号为准，不能引用旧促销。预算45分钟。

- [ ] 创建项目与子任务，设置负责人、日期和可用的前置关系。
- [ ] 邀请第二账号，测试成员能否提出调整，而非只能接受分派。
- [ ] 上传文件、评论、修改状态，寻找历史记录与提醒。
- [ ] 尝试实现“待验收→退回→重新提交→确认”，记录原生支持、配置支持或做不到。
- [ ] 查看成员或项目报表，检验能否形成课程作业需要的分工说明。

必须回答：成熟任务管理工具能覆盖建木枝多少核心流程？证据：流程截图、权限记录、报表样例。

### 03 Trello

获取：[官方价格与免费注册入口](https://trello.com/pricing)。点击免费注册，使用Atlassian账号，建立看板与卡片。官方免费版支持每工作区最多10名协作者、10个看板、单附件10MB；AI与高级能力不默认免费。预算35分钟。

- [ ] 建立待开始、进行中、待验收、需修改、已确认五列。
- [ ] 为任务卡设置成员、日期、检查清单和附件，并让第二账号提交成果。
- [ ] 尝试把卡片直接拖到已确认，判断是否存在审核权限约束，还是只有团队约定。
- [ ] 修改负责人、截止时间和文件，寻找变更历史及提醒。
- [ ] 尝试导出分工结果，区分原生导出、付费能力和第三方扩展。

必须回答：建木枝是否只是一个换成学生用语的看板？证据：首次建板耗时、验收约束、导出限制。

### 04 GroupWorks

获取：[官方免注册交互导览](https://groupworks.app/demo)。先做导览，再尝试页面上的“Start for free”。官网列出免费版最多3个活跃小组；当前检索工具未成功打开注册跳转，需用浏览器确认。预算30分钟；如受教师身份或注册条件阻挡，记录后停止，不编造身份。

- [ ] 完成偏好调查，比较工作角色、技能与时间等输入方式。
- [ ] 查看组队建议，区分“把学生组成小组”与“把任务分给组员”。
- [ ] 体验团队约定及共同确认流程，观察后续修改如何处理。
- [ ] 查看同伴评价及活动记录，区分人为评分与系统事实。
- [ ] 如能注册，再验证保存与导出；导览按钮的模拟反馈不能当作真实功能通过。将LMS或导出路线图与已上线能力分列。

必须回答：成员承诺、异议和同伴评价有哪些值得借鉴的机制？证据：标明“导览/真实账号”的截图及访问障碍。

### 05 TeamFlow AI Demo

获取：[开发者TRAE参赛帖](https://forum.trae.cn/t/topic/147784)，在“Demo体验地址”找到“TeamFlow-AI-Demo.zip”。帖内附件链接存在，但当前检索工具未成功获取文件；登录或下载要求需浏览器确认。下载后先查看说明与文件结构，再决定如何打开，不预设一定是可直接运行的HTML。预算30分钟。

- [x] 若可获取，记录运行方式；若不可获取，只做截图与文字分析并标注。
- [ ] 输入同一任务和成员信息，比较技能、可用时间与偏好如何影响分配。
- [ ] 故意降低某成员可用时间或增加高难度任务，观察是否超负荷及能否人工修改。
- [ ] 查看贡献度公式是否可解释；测试拆碎任务或反复提交是否会改变评价。
- [ ] 区分规则算法与真实模型调用、单机演示与跨账号协作；开发者帖称未来接入大模型，不能从名称推断已实现。

必须回答：哪些设计与你们重复，哪些“公平性”承诺缺少证据？证据：输入输出对照、公式说明、运行与访问状态。

## 第二轮 按需要补测

### 06 Notion

获取：[免费项目模板](https://www.notion.com/zh-cn/templates/category/free-projects-templates)；[教育权益说明](https://www.notion.com/zh-cn/help/notion-for-education)。注册后选免费模板复制到工作空间。符合资格的个人教育版为单成员空间，可与最多100位访客协作；认证学生组织有另一个方案。教育权益不等于所有AI能力免费。预算40分钟。

- [ ] 把题目原文、任务数据库和交付物放在同一工作空间。
- [ ] 配置负责人、状态、日期和关联信息，记录配置成本。
- [ ] 用访客加入，验证他能看到什么、改动什么。
- [ ] 测试历史记录、待验收流程和成员补充线下工作的方式。
- [ ] 导出一份分工说明，记录还需要多少手工排版。

必须回答：课程模板能否已解决大部分需求？

### 07 钉钉多维表

获取：[钉钉官网](https://www.dingtalk.com/)；[官方任务督办模板介绍](https://page.dingtalk.com/wow/dingtalk/default/dingtalk/KdThHVADeizvD9D?dd_mini_app_id=5000000004997171)。登录客户端，在文档或全局搜索中找“多维表”“任务管理”“工作任务督办”；具体位置随版本确认。介绍页正文抓取受限，免费额度和当前模板可用性未核实。预算30分钟。

- [ ] 找到并复制合适模板，记录是否要求组织身份或管理员操作。
- [ ] 配置负责人、日期和交付文件，试用提醒。
- [ ] 对照飞书测试相同验收流程和权限。
- [ ] 手机上完成一次提交，记录点击步骤和失败点。
- [ ] 尝试导出汇总，截图记录付费限制。

必须回答：如果同学本来就在用钉钉，他们为什么还要打开建木枝？

### 08 Slack Lists

获取：[官方Lists指南](https://slack.com/help/articles/27452748828179-Use-lists-in-Slack)；[官方试用说明](https://slack.com/help/articles/202878523-Try-a-paid-Slack-plan-for-free)。优先使用已有且获得许可的工作空间。Lists属于付费方案；没有权限时先读官方演示，试用需按官方条件申请，不默认可自动开通。预算25分钟。

- [ ] 从列表模板建任务，并尝试将频道中的需求关联到任务。
- [ ] 设置负责人、日期、子任务和相关讨论。
- [ ] 改动任务后查看版本历史及提醒。
- [ ] 测试列表共享、成员和访客的编辑范围。
- [ ] 判断任务与聊天靠近后是否减少重复录入；没获得Lists权限则标未测试。

必须回答：建木枝如何与聊天工具配合，才能减少而非增加沟通负担？

### 09 Taskade

获取：[官方注册与价格页](https://www.taskade.com/pricing)；[AI项目生成指南](https://help.taskade.com/en/articles/8958450-ai-project-studio)；[新版界面指南](https://help.taskade.com/en/articles/11967139-a-guide-to-the-new-ui)。官网当前更强调AI应用与自动化，测试时寻找Projects和项目生成能力。免费页列出2名用户及一次性AI额度；实际奖励条件、可用入口以账号为准。预算35分钟。

- [ ] 输入统一题目，让AI生成任务及子任务。
- [ ] 逐条核对题目要求，标记漏项、编造要求及不合理先后顺序。
- [ ] 改动总截止时间或一名成员可用时间，观察如何更新已有计划。
- [ ] 检查能否保留原文依据，AI能否只提建议而不直接覆盖已确认内容。
- [ ] 邀请第二用户，测试修改、协作和导出；记录一次生成消耗的额度。

必须回答：AI拆解的价值是否超过一次普通对话后复制到表格？
